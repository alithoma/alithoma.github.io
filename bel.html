Panduan Upload GitHub & Jaringan Lokal

Cara Upload ke GitHub Pages (Gratis & Permanen)

  1. Buat repository baru di akun GitHub Anda (misal: bel-cerdas-cermat).
  2. Upload file HTML ini dan pastikan namanya adalah index.html.
  3. Buka menu Settings → Pages di repository GitHub Anda.
  4. Pada bagian Branch, pilih main lalu klik Save.
  5. Dalam 1 menit, aplikasi dapat diakses melalui https://username.github.io/bel-cerdas-cermat/ dari HP/Laptop mana saja!

Cara Kerja di Jaringan Wi-Fi / LAN yang Sama

Aplikasi ini menggunakan teknologi WebRTC (Peer-to-Peer). Setelah halaman dimuat dari GitHub Pages (atau dijalankan via Live Server lokal), data tekanan bel dikirim langsung antar perangkat melalui router Wi-Fi/LAN lokal dengan latensi sangat rendah (milidetik) tanpa melewati server database eksternal.

Tips Saat Pelaksanaan Lomba

  • Pastikan HP peserta tidak masuk mode Sleep/Layar Mati agar koneksi WebRTC tetap aktif.
  • Gunakan mode Kunci Semua saat panitia membacakan soal rebutan, lalu klik Reset / Buka Bel setelah soal selesai dibacakan.
  • Jika peserta terputus karena sinyal, peserta cukup menekan tombol Gabung ulang dengan Nama Regu yang sama.
